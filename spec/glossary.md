# Glossary

Generated by `contextful-spec state` from the `[term]` tables of `spec/terms/`; not authored.

| Term | Meaning | Defined by |
| --- | --- | --- |
| audit chain | The hash-linked, segment-signed log of reads and erasures. | {{disclosure.record.segment}} |
| authoring posture | A manifest's `session` or `per_request` setting deciding whose principal authors a table write. | {{authority.issue.authoring-posture}} |
| awakeable | A single-use token that suspends a run until a caller resolves it or its deadline passes. | {{run.suspend.awakeable}} |
| build profile | A Cargo feature bundle selected at build time: `contextful-edge`, `contextful-full` or `contextful-control`. | {{topology.package.profile}} |
| cadence lease | The writer lease a reconciler holds on a deployment's cadence, so one fire runs per tick. | {{topology.coordinate.cadence-lease-ttl}} |
| capability registry | `spec/capabilities.toml`, naming each engine capability with its home path and defining symbols. | {{assurance.structure-tree.capability-registry}} |
| card | A contract's generated page listing its operations, error cases and bounds. | {{corpus.render.card}} |
| clause | One normative sentence: a list item under an operation, addressed as contract, operation and subject. | {{corpus.address.clause-id}} |
| clause pointer | A `{{id}}` reference by which one statement reaches a fact another clause owns. | {{corpus.reference.pointer}} |
| commit fence | The integer each writer lease acquisition raises by one; a commit carrying a lower commit fence loses its condition. | {{store.lease.acquire}} |
| commit lock | A table's lock held while a commit assigns its commit sequence and writes its manifest. | {{store.reserve.commit-lock-span}} |
| commit log | The `cursors/` objects through which a run under a machine writer lease commits. | {{store.lease.commit-log}} |
| compaction lease | The writer lease a compaction pass holds on one table, stamped into its snapshot and pointer. | {{store.fold.compaction-lease}} |
| conditional write | A write that succeeds only while a stored precondition holds; the one coordination primitive. | {{topology.coordinate.primitive}} |
| control receipt | The signed JSON record of one applied control version and its parent. | {{surface.apply.receipt-message}} |
| credential lease | A short-lived credential minted per scope and held in memory with its expiry; it never enters a file. | {{connector.lease.lease}} |
| credential reference | A `secret://<name>` value naming a credential by logical name, never by storage path. | {{connector.reference.reference-scheme}} |
| data boundary marker | One of the paired markers enclosing an ingested value in a model prompt, carrying its provenance label. | {{connector.infer.data-fence}} |
| decision record | A contract's ADR section holding one decision, its options and what each lost on. | {{corpus.rationale.contract-adr}} |
| delegate | Deploy-bound code outside the binary that runs a store-driven item's body over one signed HTTP request. | {{surface.delegate.binding}} |
| delegation profile | The attenuable, chain-signed credential format delegated authority travels in. | {{authority.profile.delegation-profile}} |
| denylist | The checkpoint's list of revoked credential identifiers. | {{authority.revoke.denylist}} |
| entry key | The `(execution_id, step_label, input_hash)` triple keying one journal entry. | {{run.journal.entry-key}} |
| execution owner | The one durable owner of a scope's executions, holding its connector identity and pins. | {{run.own.execution-owner}} |
| guide | A contract's non-normative teaching page, reaching each rule by pointer. | {{corpus.guide.file}} |
| hydration | Resolving a credential reference to material when a request is built, never at declaration. | {{connector.resolve.hydration-is-just-in-time}} |
| idempotency key | The key an outbound request carries, derived from its entry key, identical on every re-entry. | {{run.journal.idempotency-key}} |
| inference zone | Where a model call runs: `local:device`, `on-prem`, `private-cloud` or `public-cloud`, with an identifier. | {{authority.place.zone-string}} |
| journal | The durable record of each step's value, written once, so a resumed run replays recorded steps. | {{run.journal.step-output}} |
| lease row | A catalog row naming one writer lease's key, holder, expiry and commit fence. | {{topology.coordinate.lease-row}} |
| lede | The one paragraph opening an operation section, stating what the operation covers. | {{corpus.anatomy.lede}} |
| manifest posture | Whether a connector manifest is adopted, carrying a digest, or a template carrying a pin requirement. | {{connector.package.manifest-posture}} |
| mint credential | The one standing credential the engine presents to the mint endpoint to obtain credential leases. | {{connector.lease.bootstrap-credential}} |
| narrowing posture | Serving only publicly granted rows of a `public_only` table once its mirrored permissions pass their staleness budget. | {{disclosure.bound-staleness.public-only}} |
| node id | The path-safe name of one writing process, keying its run directories and writer leases. | {{store.lay-out.node-id-order}} |
| one home | The single engine implementation a capability resolves to, reached by every surface. | {{assurance.structure-tree.one-home}} |
| pin | A link from a clause to the test, theorem or item that demonstrates it. | {{corpus.state.pin}} |
| provenance label | The trust label a model input carries: `operator`, `ingested:first-party` or `ingested:third-party`. | {{connector.infer.provenance-order}} |
| provider chain | The ordered adapters a reference resolves through, first answer winning. | {{connector.resolve.provider-chain}} |
| purge receipt | The signed artifact a tenant purge returns, stating what the purge covers. | {{disclosure.receipt.coverage}} |
| ratchet | A recorded count the tree lowers and never raises; a live count off it fails lint. | {{corpus.registry.ceiling}} |
| reachable set | The principals and resources one subject reaches through identity links and group closure. | {{disclosure.reach.subject-principals}} |
| read frontier | A table's current snapshot and runs; a commit, fold or ledger append changes it and invalidates cached results. | {{read.cache.frontier-invalidates}} |
| replacement frontier | The newest run carrying a `replace` source's complete state; reads cover it and every later run. | {{store.declare.replace-frontier}} |
| replica | A read-only copy of a store pulled from its bucket, refusing every write verb. | {{store.replicate.descriptor}} |
| retention window | How long folded runs and superseded snapshots stay before collection removes them. | {{store.fold.retention}} |
| retrieval container | A container serving reads from a locally synced, memory-mapped snapshot set. | {{read.cache.hot-local-parquet}} |
| revocation epoch | A counter per project, tenant and principal class whose bump invalidates that slice of outstanding authority. | {{authority.revoke.epoch}} |
| revocation identifier | The identifier each credential derivation carries, withdrawing its subtree alone. | {{authority.revoke.revocation-id}} |
| run manifest | The `_manifest.json` whose conditional create commits one run's parts. | {{store.lay-out.run-manifest}} |
| sidecar | An index file beside a snapshot's parts: a vector graph, full-text index or key map, built at compaction. | {{store.index.declaration}} |
| signed store frontier | The signed statement of a store's state a reference resolver validates before resolving and answering. | {{read.reference.frontier}} |
| snapshot | An immutable compacted version of a table, named by its creation instant. | {{store.lay-out.snapshot-id}} |
| snapshot manifest | The `_manifest.json` listing a snapshot's parts and indexes with their key versions. | {{store.lay-out.snapshot-manifest}} |
| staleness budget | `max_acl_staleness`: the age mirrored source permissions reach before a read refuses. | {{disclosure.bound-staleness.budget-grammar}} |
| statement guard | The check admitting caller SQL only as one read-only SELECT over registered relations. | {{read.guard.single-read-only-statement}} |
| store identity | The UUID naming one store across its synced copies. | {{store.init.store-identity}} |
| subject tuple | The agent, host, principal, task scope, inference zone and incognito flag a credential binds. | {{authority.identify.subject-tuple}} |
| table pointer | `_pointer.json`, naming a table's current snapshot; readers reach only snapshots it reaches. | {{store.lay-out.table-pointer}} |
| topic page | A non-normative page answering one question that spans contracts by pointing at the clauses that answer it. | {{corpus.topic.file}} |
| verdict | A clause's computed state: committed when unpinned, performed when its pins qualify, broken otherwise. | {{corpus.state.verdict}} |
| why line | The indented line under a clause naming the record it rests on, or a short `because` criterion. | {{corpus.rationale.why-cell}} |
| writer lease | Time-bounded exclusive ownership of a pipeline, partition or table compaction, held by one node and renewed by conditional replace. | {{store.lease.ttl}} |
